# 🧮 Calculadora Simples

Uma calculadora moderna e responsiva desenvolvida com HTML, CSS e JavaScript.

## 🌟 Recursos

- Operações básicas: adição, subtração, multiplicação e divisão
- Interface moderna e responsiva
- Design dark mode
- Histórico de cálculos
- Suporte para números decimais
- Botões de limpar e deletar

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com Grid Layout)
- JavaScript Vanilla
- Google Fonts (Inter)

## 📦 Instalação

1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/calculadora.git
```

2. Abra o arquivo `index.html` em seu navegador

## 🎨 Design

- Tema escuro com gradiente de fundo
- Layout responsivo
- Botões com efeitos de hover e active
- Fonte moderna Inter

## 🔧 Funcionalidades

- Cálculos básicos
- Histórico de até 3 últimas operações
- Suporte a entrada de números decimais
- Botão de limpar (C)
- Botão de deletar último dígito (Del)

## 📱 Responsividade

A calculadora é totalmente responsiva e funciona bem em:
- Desktops
- Tablets
- Smartphones
